# Концепция проекта «Премиальный планировщик»

## 1. Идея продукта

«Премиальный планировщик» — персональное одностраничное веб-приложение для управления неделей, отдельными днями, целями и полезными привычками. Оно рассчитано прежде всего на занятых руководителей, предпринимателей и специалистов, которым важно видеть общую картину и быстро переходить к деталям.

Продукт должен создавать ощущение спокойного executive-инструмента: высокая информационная плотность без визуального шума, ясная иерархия, аккуратная аналитика и премиальная бело-золотая эстетика. В тёмной теме используется чёрно-золотая палитра.

Первая версия работает полностью в браузере, без регистрации, базы данных и сервера. Все пользовательские данные хранятся локально через `localStorage`.

## 2. Формат реализации

Будущая реализация состоит ровно из трёх файлов:

- `index.html` — структура единой страницы;
- `style.css` — светлая и тёмная темы, сетки, карточки и адаптация под настольный экран;
- `script.js` — логика интерфейса, календаря, перетаскивания, поиска, диктовки и хранения данных.

Целевое устройство первой версии — компьютер. Основной сценарий рассчитан на широкий экран. Мобильная версия не является обязательной частью первой реализации.

«Один экран» означает единое приложение без переходов на отдельные веб-страницы. Центральная рабочая область может переключать представления внутри общего каркаса, а крупные расписания — прокручиваться внутри своей области. Благодаря этому интерфейс остаётся цельным и не пытается одновременно показать все 36 получасовых интервалов каждого дня.

## 3. Общая структура интерфейса

Постоянный каркас приложения включает:

- компактную боковую навигацию;
- верхнюю панель с датой, переключением недели, глобальным поиском, выбором языка и темы;
- центральную рабочую область;
- правую контекстную панель или модальное окно для создания и редактирования записи.

Основные представления:

1. Обзорная панель — открывается первой.
2. Неделя — цели, привычки и календарное расписание выбранной недели.
3. День — подробный план выбранной даты.
4. Идеальная неделя — постоянный шаблон желаемого расписания.

Переход между представлениями происходит внутри той же страницы. В верхней панели доступны предыдущая и следующая неделя, возврат к текущей дате и выбор конкретной даты через календарь.

## 4. Обзорная панель

Обзорная панель даёт краткую картину текущей недели и сегодняшнего дня. На ней располагаются:

- дата, номер и диапазон текущей недели;
- сводный прогресс по четырём недельным целям;
- три привычки и их выполнение за текущую неделю;
- три главные задачи сегодняшнего дня;
- ближайшие жёсткие встречи;
- ближайшие гибкие задачи;
- небольшие показатели: выполненные задачи, занятое расписанием время, прогресс недели;
- быстрые действия: создать запись, добавить задачу, открыть день, запустить диктовку.

Аналитика должна быть компактной и полезной, без соревновательных механик, громких поздравлений, звуков и навязчивых анимаций.

## 5. Четыре цели на неделю

На каждую календарную неделю создаётся строго четыре цели. Каждая цель представлена отдельной карточкой и содержит:

- название;
- краткое описание;
- пользовательский цветовой маркер;
- список подзадач;
- рассчитанный прогресс в процентах.

Подзадачи можно добавлять, редактировать, удалять и отмечать выполненными. Прогресс цели рассчитывается автоматически как доля выполненных подзадач. Цель может быть связана с обычными записями и дневными задачами.

Если цель ещё не заполнена, на её месте сохраняется одна из четырёх карточек-заготовок. Добавить пятую цель нельзя.

## 6. Три полезные привычки

В каждой неделе отслеживаются строго три привычки. Пользователь самостоятельно вводит их названия.

Для каждой привычки показываются семь отметок — с понедельника по воскресенье. Состояние дня бинарное: выполнено или не выполнено. Нажатие на отметку меняет её состояние. Дополнительно показывается спокойный недельный результат, например `5 из 7`, без серии дней и геймификации.

Добавить четвёртую привычку нельзя. Пустые привычки отображаются как доступные для заполнения строки.

## 7. Идеальная неделя

«Идеальная неделя» — отдельный постоянный шаблон, не привязанный к конкретным календарным датам и не заменяющий фактическое расписание.

Структура шаблона:

- семь колонок — дни с понедельника по воскресенье;
- строки времени с 06:00 до 24:00;
- шаг сетки — 30 минут;
- вертикальная прокрутка внутри расписания;
- закреплённые заголовки дней и колонка времени.

Элемент создаётся нажатием на свободную ячейку. Начало определяется выбранной ячейкой, окончание можно изменить в форме записи или растягиванием блока. Один элемент может занимать несколько последовательных получасовых интервалов. Элементы можно перемещать между временем и днями с помощью drag-and-drop.

В первой версии шаблон хранится отдельно. Автоматическое копирование идеальной недели в календарную неделю не является обязательной функцией.

## 8. Представление отдельного дня

Каждый день недели имеет одинаковую структуру.

### Главные задачи

В верхней части находятся строго три главные задачи дня. Для каждой доступны отметка выполнения, заголовок, приоритет, хэштеги и связь с целью или привычкой.

### Остальные задачи

Ниже располагается список из строго десяти остальных задач. Пустые позиции остаются доступными для заполнения. Одиннадцатую задачу добавить нельзя.

### Дневное расписание

Расписание разделено на две параллельные колонки:

- «Жёсткие встречи» — события с фиксированным временем;
- «Гибкие задачи» — работы, которые можно перемещать в пределах дня.

Обе колонки используют общую шкалу с 06:00 до 24:00 и шагом 30 минут. Запись может занимать несколько интервалов. Создание выполняется нажатием на ячейку, а перенос — перетаскиванием. При изменении времени запись визуально меняет высоту и положение.

Незавершённые задачи не переносятся автоматически на следующий день или неделю. Пользователь может перенести их вручную.

## 9. Универсальная запись

Для задач, встреч и других элементов используется единая форма записи. Она содержит:

- заголовок;
- основной текст;
- дату;
- время начала и окончания;
- хэштеги;
- список названий вложенных файлов;
- статус;
- приоритет;
- необязательную связь с одной из четырёх целей;
- необязательную связь с одной из трёх привычек;
- напоминание.

Предлагаемый набор статусов: «Запланировано», «В процессе», «Выполнено», «Отложено». Приоритеты: низкий, обычный, высокий.

Напоминание в первой локальной версии отображается внутри открытого приложения. Фоновая системная доставка уведомлений после закрытия страницы не гарантируется без дополнительных браузерных механизмов.

## 10. Хэштеги и поиск

Хэштег добавляется свободным вводом через символ `#`. Один элемент может иметь несколько тегов.

Глобальный поиск в верхней панели ищет одновременно по:

- задачам;
- целям и их подзадачам;
- обычным записям;
- хэштегам.

Результаты группируются по типу и позволяют перейти к соответствующей неделе, дню или записи. Нажатие на хэштег включает фильтр по нему.

## 11. Вложения

В первой версии можно выбрать файл любого типа размером до 10 МБ. Это ограничение подготавливает интерфейс к возможной полноценной работе с файлами в будущем.

В `localStorage` сохраняется только название выбранного файла. Сам файл, его содержимое и локальный путь не сохраняются, поэтому после повторного открытия страницы файл нельзя скачать или открыть из планировщика. Интерфейс должен честно обозначать это как «название вложения», а не создавать впечатление облачного хранения.

## 12. Telegram и визитка отправителя

Интеграция с Telegram в первой версии не выполняет реальную отправку. В форме записи предусматривается премиальный визуальный блок «Поделиться в Telegram»:

- узнаваемая, но вписанная в общий стиль Telegram-графика;
- мини-превью будущего сообщения;
- визитка отправителя;
- неактивная кнопка или статус «Скоро».

Нажатие не открывает Telegram и не передаёт данные. Этот блок служит подготовленным местом для будущей интеграции.

Общая визитка настраивается один раз и содержит:

- имя;
- компанию;
- Telegram;
- email.

Она оформляется как небольшая чёрная или белая премиальная карточка с золотыми деталями и автоматически показывается в превью будущей отправки.

## 13. Ручной ввод и диктовка

Текст записи можно напечатать вручную или надиктовать через встроенный браузерный Web Speech API.

Поддерживаются русский и английский языки. В интерфейсе доступны режимы `RU`, `EN` и `AUTO`. Поскольку фактическое автоматическое распознавание нескольких языков зависит от конкретного браузера, режим `AUTO` использует доступные возможности браузера или его текущий язык; при необходимости пользователь сможет быстро переключить язык вручную.

Распознанный текст появляется в поле записи и может быть отредактирован до сохранения. Исходное аудио не сохраняется. Интерфейс сообщает, если браузер не поддерживает распознавание речи, и предупреждает, что обработка голоса может выполняться внешним сервисом браузера.

## 14. Визуальный стиль

Направление — современный executive-dashboard с карточками и сдержанной аналитикой.

### Светлая тема

- тёплый белый и оттенок слоновой кости для фона;
- чистые белые карточки;
- шампанское и приглушённое золото для акцентов;
- графитовый основной текст;
- тонкие тёпло-серые границы;
- мягкие, короткие тени.

### Тёмная тема

- глубокий чёрный и антрацитовый фон;
- графитовые карточки;
- матовые золотые акценты;
- светлый текст без резкого чисто-белого контраста.

Золото используется дозированно: активные состояния, тонкие линии, иконки, прогресс и ключевые действия. Интерфейс не должен выглядеть блестящим, тяжёлым или декоративно перегруженным.

Рекомендуются крупные спокойные отступы, чёткая типографика, небольшие скругления, лаконичные линейные иконки и едва заметные переходы состояний. Звуки, конфетти и интенсивные анимации отсутствуют.

## 15. Темы и языки

Пользователь может переключаться между светлой и тёмной темой. Выбор сохраняется в `localStorage`.

Интерфейс двуязычный: русский и английский. Переключатель `RU / EN` находится в верхней панели, выбранный язык также сохраняется. Пользовательский текст не переводится — меняются только системные подписи, кнопки, статусы, подсказки и сообщения.

## 16. Локальное хранение данных

В `localStorage` сохраняются:

- настройки темы и языка;
- выбранная дата и последнее открытое представление;
- календарные недели;
- четыре цели каждой недели и их подзадачи;
- три привычки и ежедневные отметки;
- дневные задачи и расписание;
- шаблон идеальной недели;
- записи, хэштеги и названия вложений;
- общая визитка отправителя.

Данные логически разделяются по версиям схемы, чтобы последующие обновления приложения могли выполнять миграцию. Сохранение производится после каждого значимого действия, а чтение — при запуске страницы.

Важно: очистка данных сайта в браузере удалит содержимое планировщика. Экспорт и импорт резервной копии не входят в подтверждённый объём первой версии и могут быть добавлены отдельным решением.

## 17. Ограничения первой версии

- Нет сервера, базы данных, регистрации и синхронизации между устройствами.
- Нет совместной работы нескольких пользователей.
- Нет автоматического переноса незавершённых задач.
- Нет реальной отправки в Telegram.
- Содержимое вложенных файлов не хранится; сохраняются только их названия.
- Нет гарантированных уведомлений, когда страница закрыта.
- Распознавание речи зависит от браузера и его разрешений.
- Автоматическое многоязычное распознавание может работать по-разному в разных браузерах.
- Основной интерфейс оптимизирован для компьютера.

## 18. Критерии готовности будущей реализации

Первая версия считается соответствующей концепции, если:

1. Приложение открывается обзорной панелью и работает как единая страница.
2. Можно переходить по неделям и выбирать конкретную дату.
3. Для недели доступны ровно четыре цели и три привычки.
4. Для дня доступны ровно три главные и десять остальных задач.
5. Дневное расписание имеет две колонки и интервалы с 06:00 до 24:00.
6. Идеальная неделя существует как отдельный постоянный шаблон.
7. Записи создаются нажатием на ячейку, занимают несколько интервалов и перетаскиваются.
8. Работают редактирование записей, статусы, приоритеты, связи, хэштеги и глобальный поиск.
9. Можно выбрать вложение, при этом сохраняется только его название.
10. Отображаются визитка и неактивное премиальное превью Telegram.
11. Работает ручной ввод и, в поддерживаемом браузере, голосовая транскрибация.
12. Работают светлая бело-золотая и тёмная чёрно-золотая темы.
13. Работает переключение русского и английского интерфейса.
14. После перезагрузки страницы данные восстанавливаются из `localStorage`.
