# План разработки «Премиального планировщика»

## Общие правила выполнения

- Источник требований — `tz.md`; новые функции вне ТЗ не добавляются.
- Итоговая реализация состоит только из `index.html`, `style.css` и `script.js`.
- Используются чистые HTML, CSS и JavaScript без библиотек, CDN и внешних шрифтов.
- Целевой браузер — актуальный настольный Google Chrome, минимальное окно `1280 × 720`, оптимальное — `1440 × 900` и больше.
- После каждого этапа приложение должно запускаться и предоставлять законченный пользовательский результат, а не набор незавершённых заготовок.
- После каждого изменения сначала выполняются доступные автоматические проверки: синтаксис, консоль, действия в браузере, сохранение и восстановление данных, граничные условия.
- Ручная проверка пользователя ограничивается тем, что нельзя достоверно оценить автоматически: внешний вид, понятность, визуальный комфорт и удобство взаимодействия.
- Найденные автоматическими проверками ошибки исправляются до передачи этапа пользователю.
- Тестовые данные после проверки удаляются или заменяются чистым состоянием.
